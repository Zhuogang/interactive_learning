# Learning How to Learn

The starter deck: 10 concepts and 51 cards that quiz you on [PRINCIPLES.md](../../PRINCIPLES.md). You learn the method by using it.

Try the cards before you read the principles. Each concept starts with a guess, and wrong guesses help.
